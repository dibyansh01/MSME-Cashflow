# Operational Runbooks

Standard Operating Procedures (SOPs) for systems management, database migrations, and incident recovery.

## Planned Runbooks
- **Database Backup & Disaster Restore:** Verifying automated pg_dump backups and testing dry-run restore.
- **Migration Rollback:** Safely rolling back non-destructive Prisma schema migrations.
- **WhatsApp Provider Failover:** Handling message broker downtime and falling back to direct deep links.
